# 🚀 Task Master: Full-Stack productivity App

A professional task management system built to demonstrate full-stack proficiency.

### 🛠 Tech Stack
- **Frontend:** React, Tailwind CSS, Vite, Axios
- **Backend:** Node.js, Express, Sequelize ORM
- **Database:** SQLite (Relational)
- **Security:** Bcrypt Password Hashing, Environment Variables

### ✨ Features
- **Secure Authentication:** User registration and login with encrypted passwords.
- **Dynamic Progress:** A real-time progress bar that tracks completion percentage.
- **Responsive Design:** Fully optimized for mobile and desktop using Tailwind.
- **Search & Filter:** Instantly find tasks using the built-in search logic.

### 💻 Installation
1. Clone: `git clone https://github.com/Abrham21-lab/Task-Master-Fullstack.git`
2. **Backend:** `cd server && npm install && node server.js`
3. **Frontend:** `cd client && npm install && npm run dev`
